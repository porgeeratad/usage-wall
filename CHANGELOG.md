# Changelog

## 1.0.0

First public release.

- Menu bar app with the local server inside; shows the wall full screen on a dedicated display or in a window
- Show On menu, `usage-wall` command, displays remembered by UUID, follows hot-plug
- Clawd in four stages with walk / idle animations, day and night scene, RESET sign with the weekday
- Numbers from Claude Code's status line by default (no token, no network); opt-in sign-in mode reads the usage
  endpoint with your Claude Code sign-in
- `install.sh` / `uninstall.sh`, `usage-wall` command
